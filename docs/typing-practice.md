# 随机打字练习

随机练习位于热力图下，直接订阅现有键盘钩子的 TextInput 事件，无需点击输入框。它跟随键盘记录的开始和暂停；钩子仍正常传播按键，其他应用可正常接收输入。Ctrl、Alt、Win 组合键不写入练习。字符按前台键盘布局转换，支持 Shift 标点、空格、退格和回车。

输入按“光标 + 落子”记账，而不是往字符串末尾追加：每个键落在正文哪一格由当前位置决定。追加式缓冲只要中间少一个字符，后面每一位都会错位，进度永远停在 N−1/N，再多敲也补不回那一格。落不中光标时允许向前找两格，正好接住漏敲的词间空格或一个字母，被跨过的格子计入错误；两格内仍对不上的键被拒收，计一次错并把当前词标红，光标原地不动。退格回到上一子落下的位置，连带它当时跨过的格子一起退回。回车是唯一的检查动作：光标推到正文末尾即整句落齐并自动过关，还差四格以内由程序补上收尾，差得多则先把未落进去的格子标红并提示、再按一次回车跳过剩下的。跳过、拒收、提交时补上的格子都算错误，分数照扣。大小写不敏感，标点照写，弯直引号与中文全角标点等价。每句完成只计分一次：max(10, 字符数 × 2 + 100 − 落子错误次数 × 10)。开启自动换句时，过关即换下一句。

成绩保存在 `%APPDATA%/XAssistant/practice-scores.json`（Debug 为 `XAssistant_Dev`）。历史成绩保留，损坏文件不会被覆盖。界面保留成绩与最近练习，进度条下方一行显示当前句的判定与提示，不堆玩法说明。

## 题库

题库按「语言目录 / 句式文件」两级分档：`Assets/Practice/英语/*.json`、`Assets/Practice/日语/*.json`，整个目录随构建与发布复制。加载器 `PracticeScoreStore.LoadCatalogTree` 扫根目录下所有 JSON，一级目录名写入 `Language`，文件名写入 `Category`（文件里的 `name` 可覆盖显示名），JSON 里重复写的 `category` 一律不算——分类以文件位置为凭，不然目录和字段会各说一套。直接躺在根下的文件归进「通用」，不因为缺一级目录就整个题库加载不了。界面按这个结构给两个下拉：先选语言再选句式，句式候选跟着语言收窄。当前 2 门语言 / 12 个句式 / 76 句。

一个文件 = 一个句式：

```json
{
  "version": 1,
  "note": "本句式的转写约定，悬停在筛选下拉上显示",
  "mask": true,
  "sentences": [{
    "id": "ja-kata-cafe",
    "source": "日语 · 片假名外来语原创",
    "sourceUrl": "",
    "translation": "我要咖啡和蛋糕。",
    "words": [{"text": "koohii", "annotation": "コーヒー", "translation": "咖啡", "suffix": ""}]
  }]
}
```

`text` 是要敲出来的形式，`annotation` 是卡片上方的注音：英文写 IPA，日语写假名或「汉字（假名读法）」。`mask` 为真时字母先遮成 `_`、敲对了才显形，用于看假名默写罗马音的闭卷句式；此时悬停提示只给假名与词义，不漏答案。词之间自动插入一个空格，标点放在 suffix；每词必须有注音与释义。注音为静态文本，无语音 API。莎士比亚题目来源链接记录于 sourceUrl；译文和词义为练习用简译。

日语句式敲的是罗马音，按读音转写而不进输入法，转写约定写在文件的 `note` 里：长音双写元音（`とうきょう → tookyoo`、`コーヒー → koohii`、`テーブル → teeburu`），促音双写后一个子音（`きっと → kitto`、`しゅっしん → shusshin`），助词按读音（`は → wa`、`へ → e`、`を → o`），拨音写 `n`、只在会与后面的元音连读时加撇（`さんい → san'i`）。

出题约束：

- `text` 与 `suffix` 只能是可打印 ASCII——键盘钩子只打得这些出来，正文里混进假名、长音符或全角标点就成了敲不进去的死格。所以 `kōhī` 写 `koohii`，句号用 `.` 不用 `。`（`PracticeCatalog.Validate` 会直接拒收非 ASCII 正文）。
- 一个 `text` 只写一个词，不掺空格。切词逻辑 `PracticeText.Tokens`（正则 `[\p{L}\p{N}]+(?:'[\p{L}\p{N}]+)*`）把 `summer's`、`o'clock`、`Let's` 视为一个词，而 `well-being`、`'em` 会被切开或丢首撇号；注音与释义逐词对齐，词被拆碎后注释就对不上正文。
- `suffix` 只放标点（`. , ; : ! ?`），不能含字母数字；标点计入抄写字符数，抄写时忽略大小写、弯直引号等价，因此正文里的弯引号要写成 `PracticeText.Normalize` 后的直引号形式。
- 数字题把阿拉伯数字写进 `text`，注音写读法（如 `42` → `ˌfɔːti ˈtuː`），释义写中文数词；标点会把 `11:30` 拆成两段，避免这类写法。
- 一句可以含多个句子（句号后照常大写），例如 `Talk is cheap. Show me the code.`；`Text` 由 `text + suffix` 以单空格拼接，正文长度与词数分别受 300 字符与 28 词限制。
- 校验以真实代码为准：`PracticeCatalog.Validate` 拒收空字段、重复 ID、缺语言或句式分类、非 ASCII 正文与超限句子；`release/typing-games/catalog-check` 用编译产物复现该加载路径，并逐句检查切词与单词一一对应。

## 验证

离屏夹具按目录加载全题库 76 句，逐字符喂进 `PracticeViewModel`（不启界面、不装钩子、不写成绩文件），场景包含：正文敲完、漏敲中间一个字母、漏敲中间一个空格、词间多敲一个空格、中间混进一个错键、停在错键上、差 8 格连按两次回车、只差最后一格按回车，共 8 个场景；另对每个闭卷句式断言“初始字母全遮、敲完全部显形”。过关判定、错误计数、标红三项与期望全部相符，完美抄写零错记。另模拟钩子订阅与原生钩子回调验证字符输入、Shift 标点、快捷键过滤、退格、回车和事件解绑；WPF 深浅主题及完整单页离屏渲染检查。未启动真实全局监听，未改动真实统计数据。
