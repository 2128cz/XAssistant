# 速记单实例复用用标题标记匹配，而非进程 PID

最初拟用「PID + 可见窗口检测」判断捕获窗是否已打开：XAssistant 记录 `Process.Start` 返回的浏览器 PID，热键触发时若该 PID 仍有可见窗口则置顶聚焦，否则重开。实测发现该方案在 Chrome/Edge 已运行时失效——`chrome.exe --app=<url>` 启动的进程是转发器，命令被转交给既有浏览器主实例、转发器随即退出，窗口实际属于主实例，PID 追踪不到。改为标题标记匹配：xapp 捕获视图把页面标题设为固定前缀「灵感速记」，XAssistant 枚举可见顶层窗口、按「chrome/edge 进程 + 标题前缀」判定捕获窗是否打开；打开则 `SetForegroundWindow` 置顶聚焦，否则重开带当前来源。该方案不依赖 PID、免疫转发器与浏览器后台进程残留。

- **Consequences**: 与 xapp 捕获视图形成契约——页面标题必须以「灵感速记」开头（ticket 03 落地）；来源只在判定为「未打开」时新开写入，保证已输入内容与来源不被覆盖。
